# fastapi-url-shortner 🚀

* FastLink is a simple URL shortener web application built with FastAPI.
It converts long URLs into short and easy-to-share links.

## Features

-  Create short URLs
-  Redirect short links to original URLs
-  Copy short Urls
-  Click count tracking
-  Delete short URLs
-  SQLite database storage
-  View all created links
-  FastApi backend

## Tech Stack

-  Python
-  FastAPI
-  SQLite
-  SQLAlchemy
-  HTML
-  CSS

## How to use this project?

-  Install Python on your system.

-  Run the following command in your terminal.
'''bash
pip install -r requirements.txt
'''

-  Clone the repository to your local system.

-  Enter into the project directory.
'''bash
cd url_shortener
'''

-  Create Virtual Environment by running following command.
'''bash
python -m venv venv
'''
-install requirements  
'''bash
pip install -r requirements.txt
'''

-  Run the application using following command.
'''bash
uvicorn app:app --reload
'''

-  Open your browser and visit:
'''bash
http://127.0.0.1:8000
'''

-  Hola, It's running !! 🚀
